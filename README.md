# 📈 Stock Market Analysis using Python

## Overview

This project analyzes historical stock market data using Python and performs data cleaning, feature engineering, statistical analysis, and data visualization.

The project helps understand stock price trends, trading volume, daily returns, volatility, and correlations between stock attributes through various charts and graphs.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## Features

### Data Preprocessing

* Load stock market dataset
* Handle missing values
* Convert date columns
* Sort data chronologically

### Feature Engineering

* Daily Return Calculation
* 20-Day Moving Average
* 50-Day Moving Average
* Volatility Analysis

### Statistical Analysis

* Best Gain Day
* Worst Loss Day
* Average Daily Return
* Risk Measurement
* Volatility Insights

### Data Visualization

* Closing Price Trend (Line Chart)
* Moving Average Analysis (Line Chart)
* Trading Volume Analysis (Bar Chart)
* Correlation Heatmap
* Daily Return Trend (Line Chart)
* Volatility Distribution (Pie Chart)

## Installation

Clone the repository:

```bash

```

Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

From the project root directory:

